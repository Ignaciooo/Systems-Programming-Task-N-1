# Student Grade Calculation System (OOP Implementation)

A C++ application designed to process, calculate, and manage student academic performance. The system calculates final grades based on homework assignments and exam results, utilizing modern object-oriented programming (OOP) principles, standard template library (STL) containers, and file I/O operations.

# Final Grade Calculation Formula

Final Points = 0.4 * (Average of HW / Median of HW) + 0.6 * Exam
